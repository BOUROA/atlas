# Maquetas

Propuestas en HTML estático; ábrelas en el navegador. En cada pantalla se propusieron varias direcciones y se construyó una. Las descartadas quedan como alternativas por si prefieres otro estilo.

| Pantalla | Elegida | Descartadas |
|---|---|---|
| Dirección visual de toda la app | `observatorio` (cielo nocturno, estrellas) | `cuaderno` (papel, tinta), `estudio` (oscuro y sobrio, tipo herramienta) |
| Hoy: densidad | `hoy-iconos` (compacta, con iconos) | `hoy-calma` (más aire, menos datos); `hoy-actual.png` es el punto de partida |
| Misión del día | `mision-cadena` (cadena de misiones) | `mision-lista` (lista ordenada) |
| Camino por asignatura | `camino-sendero` (sendero de estrellas) | `camino-escalera` (escalera de niveles) |
| Rumbo a los exámenes | `rumbo-b` + la carta de `rumbo-a` | `rumbo-c` |

Los `.png` son capturas de cada maqueta; los `-390.png`, su versión de móvil.
